<img src="./hd-about-this-page.svg" width="620" alt="about this page"/>

Every graphic in the hero and stats sections is generated in this repo — not<br>
loaded from a third-party stats card service. `ascii.svg` comes from<br>
[`scripts/make_portrait.py`](scripts/make_portrait.py); the contribution graphics<br>
and section headings are drawn by [a daily action](.github/workflows/stats.yml)<br>
from the GitHub GraphQL API, committing only when numbers change.

Language totals are **public repositories only**. The year map uses the same<br>
character ramp as the portrait (`:` `+` `#` `@`). The profile view counter at<br>
the top is the one exception still served externally so the count keeps working.
